Where to start

46 lessons, 7 modules

Each lesson is a short read plus a diagram, worked example, pitfalls, self-check questions and a hands-on lab you can do against code you already own.

Context Engineering

Prompt engineering asks "what words do I write?" Context engineering asks "what is the smallest set of high-signal tokens that makes the desired behaviour most likely — and how does my system keep that true over a long-running task?"

Interactive: context budget allocator

Pattern catalog

Twenty-two named, reusable context-engineering patterns. Each states the problem, the mechanism, the cost, and the failure mode you inherit when you adopt it.

Lessons in this pillar

14 real application case studies

These are not links to external reading. Each case is a complete, self-contained design document: product brief, architecture diagram, request trace, the exact context assembled per call, tool boundaries, cost model, failure simulations, evaluation suite, and interactive design decisions with graded feedback.

Interactive labs

Sixteen offline simulations. They are deliberately simplified teaching models — not provider internals — but every one encodes a real engineering trade-off you will meet in production.

Decision workshop

Thirty graded engineering decisions. Pick an answer and get the reasoning — including why the plausible-but-wrong option is tempting.

Reference library

Glossary, cheat sheets, formulas and a cited source list. Everything needed to use this site is embedded locally; the source list tells you where each idea originates so you can verify it.

Offline Course Library

The academy is one opinionated course. The library is everyone else's, read in one place: point it at course repositories on your disk and it builds a searchable tree, then maps them onto the seven modules here so the external material lands in the right order.
